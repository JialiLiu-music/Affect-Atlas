# 探索性窗口曲线升级记录

2026-10-12。用户授权整体预测＋探索性滑动窗口评分＋播放联动＋JSON/CSV导出，不新增训练或论文实验。

## 后端协议

- 整体预测保留原算法：整段float32时间均值→既有mean_mlp。
- 新增`result.timeline`：固定10秒窗口、5秒步长，D≤10秒返回一个整段窗口，长音频尾部追加最后完整长度窗口；中心时刻用于图定位，同时保存实际起止时间和参与bin数。
- MERT只提取一次整段音频特征；每个窗口选择已有1Hz中心bin，再用同一来源head预测。复用完整音频上下文，不等同每个独立音频裁剪重提特征。
- 不平滑、不校正，不裁剪原始预测（display字段仅可供二维图定位）。`validated_dynamic_model=false`明确这是静态模型的探索性局部应用；10秒窗口短于原45秒训练片段，局部准确性未验证。
- 1.5秒边界允许包含中心恰等于末端的有效partial bin，其他窗口采用半开区间；无重复尾窗、超出时长或空窗口。
- 时长拒绝信息加入实际解码秒数。
